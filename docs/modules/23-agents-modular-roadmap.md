## 1. Что хочет юзер (резюме ТЗ + доп-требования)

### Из ТЗ (Project Loom v0.1 — кодовое имя, не бренд)

**Концепция:** дружелюбное ядро-оркестратор + магазин подключаемых модулей. Каждый модуль — изолированный навык с собственной памятью, инструментами, прокачкой L0→L4. Модуль СО ВРЕМЕНЕМ становится «личным экспертом» — это главный дифференциатор от ChatGPT/Claude/GPTs.

**Ключевые принципы:**
- Friendly-first (без жаргона, единый персонаж)
- Модульность (контракт `module.yaml`, изолированные песочницы)
- Мульти-LLM по силе (Claude / GPT / Grok / Perplexity, роутер выбирает)
- Самообучение через RAG + Adaptive System Prompts (НЕ fine-tuning базовой LLM)
- Кросс-платформенность (web + mobile)
- 152-ФЗ compliance, права на экспорт/удаление

**Архитектура (4 слоя):**
1. **Интерфейсный** — Frontend / Mobile / API
2. **Оркестратор (ядро)** — Intent Recognition · LLM Router · Context Manager · Memory Hub · Personality Layer · Permission Broker · Action Logger · Module Marketplace API
3. **Слой модулей** — изолированные навыки
4. **Слой данных** — Postgres + векторная БД + S3 + Redis

**LLM Router (раздел 4 ТЗ) — критический компонент:**
- 4 паттерна: Pipeline / Parallel ensemble / Verify / Specialist routing
- Cost-aware (дешёвые для простого, флагманы для сложного)
- Семантический кэш (экономия 30-50%)
- Бюджеты по тарифу
- Health-checks + fallback + circuit breaker

**Прокачка модулей (раздел 5):**

| L | Название | Что умеет | Условие |
|---|---|---|---|
| L0 | Базовый | Универсальные ответы | По умолчанию |
| L1 | Знакомство | Знает базовые факты о юзере и задаче | 5-10 взаимодействий + onboarding |
| L2 | Адаптация | Подстраивается под стиль, использует терминологию юзера | Подключён источник + 30 взаимодействий |
| L3 | Эксперт | Действует проактивно, замечает аномалии | Накоплена база + 4+ недели регулярного использования |
| L4 | Автономия | Выполняет рутинные действия без подтверждения | Явное разрешение юзера + история без ошибок |

**Память (3 уровня):**
- Глобальный профиль (имя, тон, предпочтения) — read всеми модулями
- Модульная (изолированная) — read/write только своим модулем
- Эпизодическая (история диалогов) — оркестратор + текущий модуль

**MVP-модули (ТЗ предлагает):** Почта (Gmail), Календарь, Питание, Заметки.
**1.0 (бизнес):** Яндекс.Директ, CRM, аналитика.
**2.0:** SDK для маркетплейса третьих модулей, L4-автономия, командные модули.

**Тарифы:** Free (1-2 модуля, L0-L1) → Pro (все базовые, L0-L3) → Business (бизнес-модули, L4, мульти-аккаунт).

### Доп-требования от юзера (2026-05-16 в чате, не в ТЗ)

1. **Мобильное приложение с упрощёнными вкладками** — install из главного окна
2. **ИИ агент = текстовое управление как в Telegram** (главный экран — чат)
3. **Бизнес решения помельче** в мобильном
4. **Чат-боты минимальный стек управления** в мобильном (только on/off, метрики)
5. **Сайты не делаем** в мобильном (только с компа)
6. **КП — только шаблоны** в мобильном
7. **Весь функционал доступен с приложения**, включая пополнение баланса
8. **API соц-сетей** — X, YouTube, Instagram + RU-альтернативы

## 3. Мобильное — только PWA (решение юзера 2026-05-16)

**Native приложение НЕ делаем.** Юзер прямо сказал: «приложение мы не делаем пока отдельно, мы адаптируем как приложение через сохранение быстрой ссылки на рабочий стол». То есть:

- ❌ Никакого React Native, Apple Developer ($99/год), Google Play ($25), App Store submission
- ✅ **PWA** — `manifest.json` + service worker + meta-tags + Add-to-Home-Screen
- ✅ Юзер на iPhone: «Поделиться → На экран Домой» → иконка как нативное приложение, fullscreen
- ✅ На Android Chrome: автоматический баннер «Установить» через `beforeinstallprompt`
- ✅ Та же web-страница aiche.ru — просто с правильным манифестом и адаптивной вёрсткой

**Push в MVP не делаем** (юзер: «потом добавим»). В проекте уже есть VAPID-инфраструктура ([модуль 17](17-push.md)) — её можно расширить когда понадобится. Работает в Android PWA из коробки, в iOS PWA — с iOS 16.4+.

### Упрощённые вкладки (адаптивная вёрстка для моб)

```
🏠 Чат           ← главный (текстовое управление Loom-агентом)
💼 Решения       ← Бизнес-решения (компактные карточки)
💬 Боты          ← список ботов, on/off, метрики (без редактора)
📄 КП            ← выбор шаблона → заполнить → отправить (без сложного редактора)
📚 Знания        ← Knowledge Hub (все категории, поиск)
💰 Кошелёк       ← баланс + пополнить (Apple Pay / СБП)
👤 Профиль       ← настройки, привязки соц.сетей, выход
```

**НЕ будет в моб:**
- Конструктор сайтов (только с компа)
- Canvas-редактор workflow
- Админка
- Сложные настройки шаблонов КП (только выбор готового)

## 5. План фаз (итеративный)

### Фаза 0 — Фундамент (1-2 недели)

Не ломаем существующее, надстраиваем.

- **LLM Router** ([server/llm_router.py](../../server/llm_router.py) — новый):
  - Классификация запроса (тип / сложность / чувствительность)
  - Матрица из ТЗ раздела 4.2 (4 паттерна: Pipeline / Parallel / Verify / Specialist)
  - Cost-aware: дешёвые для простого, флагманы для сложного
  - Health-check + fallback + circuit breaker
  - **Использует все 4 ключа уже в БД:** Anthropic ✅, OpenAI ✅, Grok `xai-X4UU...` ✅, Perplexity ✅
- **Module manifest** — обернуть 48 ролей из [registry.py](../../server/agents/registry.py) в `server/agents/manifests/*.yaml`. Регистратор читает из YAML.
- **Семантический кэш** — `llm_cache` таблица + similarity check перед вызовом (экономия 30-50%)
- **PWA включить** — `views/manifest.json` + service worker + install banner для Android + iOS meta-tags
- **Адаптивная вёрстка для моб** — 7 упрощённых вкладок поверх существующего HTML

### Фаза 1 — MVP модуля «ИИ Агенты» (3-4 недели)

- **Memory Hub** — таблица `user_global_profile` + RAG поверх неё
- **Module Memory** — таблица `module_memory` (per user+module, JSON правила + векторы)
- **Прокачка L0→L2** — таблица `module_levels`, UI карточек модуля с прогрессом, условия перехода
- **Adaptive System Prompts** — выученные правила подмешиваются перед каждым вызовом
- **Personality Layer** — финальный normalize-stage в оркестраторе (одна модель приводит всё к единому тону)
- **Multi-level delegate** — расширить tool `delegate` чтобы Agent B мог тоже делегировать
- **3 первых модуля с прокачкой** (proof-of-concept, согласовано 2026-05-16):
  - **📧 Почта** — Gmail OAuth + Yandex IMAP fallback. Прокачка: стиль писем, тон с разными адресатами
  - **✍️ Копирайтер с прокачкой** — расширение Креаторов как первый Loom-модуль. Прокачка: tone of voice, аудитория, импорт прошлых постов VK/TG
  - **💰 Финансы личные** — CSV-импорт выписки (любой банк). Прокачка: категории, регулярные платежи. (Tinkoff Open API позже опционально)

### Фаза 2 — Расширение модулей (3-4 недели)

- **+3 модуля v1.0** из ТЗ:
  - **📅 Календарь** — Google Calendar OAuth + Yandex CalDAV
  - **🥗 Питание** — дневник + советы (без интеграций, ручной ввод + AI)
  - **📝 Заметки** — личная база знаний, импорт, поиск (расширение существующего Knowledge Hub)
- **Push через VAPID** (web push — уже есть в проекте, [модуль 17](17-push.md)) для critical-уведомлений модулей

### Фаза 3 — Бизнес-модули + Advanced (4-6 недель)

- **Бизнес-модули в каталоге** (сразу B2B по решению юзера):
  - **🎯 Яндекс.Директ** — OAuth + управление кампаниями
  - **📊 Аналитика** — Yandex.Metrika + Excel/CSV анализ
  - **📇 CRM-помощник** — карточки клиентов, напоминания
- **Permission Broker** + L3-L4 прокачка
- **Командные модули** (общая база команды) — **отложено в v2.0** по ТЗ
- **Module marketplace SDK** — третьи разработчики (v2.0)
- **fine-tuning add-on** (опц., для дорогих тарифов)

- **Не переписываем существующее с нуля.** Loom = надстройка поверх AI Студии Че.
- **Не делаем fine-tuning базовых LLM в MVP** — только RAG + Adaptive Prompts (как в ТЗ разд. 5.3).
- **Не запускаем маркетплейс модулей в MVP** — это v2.0.
- **Не пилим Apple Native (Swift) / Android Native (Kotlin) отдельно** — React Native единая кодбаза.
- **Не делаем web-only без планирования mobile** — UX-решения с учётом мобильного с первого дня.

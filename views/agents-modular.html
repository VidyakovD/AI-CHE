⏰ Расписание агента

Агент будет автоматически выполнять задачу по расписанию. Каждый запуск стоит как обычный вызов модуля (1 ₽).

Без задачи расписание не сработает — модулю нужно понять что делать.

Протестировать прямо сейчас — запустит модуль с задачей выше (с биллингом 1 ₽).
📨 Webhook-триггер — дёргать модуль по URL из CRM / Zapier / webhook'ов.

📲 Где использовать Че

Че — один помощник, доступный отовсюду. История и память синхронизируются между каналами.

💻
Веб ✓ сейчас
Ты прямо сейчас здесь — aiche.ru/agents-modular.html в браузере. Полный функционал.
📱
Приложение на телефон / компьютер ✓ установлено доступно
Сохрани Че на главный экран — иконка, без адресной строки, работает офлайн.
🤖 Android (Chrome)
Нажми «📥 Установить» выше. Если кнопка не появилась — меню браузера «⋮» → «Установить приложение».
🍎 iOS (Safari)
Кнопка «Поделиться» внизу (квадрат со стрелкой ↑) → «На экран «Домой»» → «Добавить».
💻 Desktop (Chrome, Edge, Arc)
Нажми «📥 Установить» выше. Или: иконка установки в правом углу адресной строки.
✈
Telegram-бот ⏳ скоро
Пишешь в Telegram → Че отвечает там же, делегирует модулям, история общая с веб. Без установки приложения.
🇷🇺
MAX-бот ⏳ скоро
Российский мессенджер MAX от VK — для пользователей без VPN. Тот же чат с Че, что и в TG.

💡 Подключённые TG/MAX будут пушить тебя если Че/модули закончили работу (например cron-расписание сделало пост → ты узнаешь в TG).

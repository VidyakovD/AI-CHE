🔑 Авторизация

Все запросы к /api/v1/* требуют заголовок:

Authorization: Bearer ai_che_<prefix>_<secret>

Получите токен на вкладке «🔑 Токены». Секрет показывается ОДИН РАЗ при создании.

📋 Эндпоинты

GET/api/v1/meПрофиль + баланс
POST/api/v1/proposals/generateproposalsСгенерировать КП
GET/api/v1/proposals/{id}proposalsПолучить КП

💡 Пример: создать КП

curl -X POST https://aiche.ru/api/v1/proposals/generate \
  -H "Authorization: Bearer ai_che_xxxx_yyyy" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "КП для ИП Иванов",
    "client_name": "ИП Иванов",
    "client_email": "ivanov@example.com",
    "client_request": "Нужен лендинг для онлайн-курсов по дизайну",
    "client_site_url": "https://ivanov.com"
  }'

Ответ:

{
  "proposal_id": 123,
  "name": "КП для ИП Иванов",
  "pdf_url": "/uploads/proposals/proposal_123.pdf",
  "cost_kop": 5000
}

🔗 Webhooks: получение событий

Когда событие происходит (КП открыто клиентом, заявка из бота...), мы делаем POST на ваш URL с JSON-payload:

{
  "event": "proposal.opened",
  "timestamp": "2026-05-04T14:23:11Z",
  "data": {
    "proposal_id": 123,
    "name": "КП для ИП Иванов",
    "client_name": "ИП Иванов",
    "client_email": "ivanov@example.com",
    "opened_at": "2026-05-04T14:23:11Z"
  }
}

События:

proposal.opened proposal.sent record.created solution.done site.done site.failed

Верификация подписи:

Каждый POST приходит с заголовком X-Aiche-Signature:

X-Aiche-Signature: sha256=<hmac-sha256-hex>

Где hex = HMAC-SHA256(secret, request.body). Пример Python:

import hmac, hashlib
def verify(secret, body_bytes, signature_header):
    expected = "sha256=" + hmac.new(
        secret.encode(), body_bytes, hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(expected, signature_header)

Retry:

Таймаут 10 сек. Если ваш сервер вернул 5xx или не ответил — у webhook увеличивается fail_count. После 10 неудач подряд webhook автоматически отключается (видно в этом разделе).

⚠️ Лимиты и защита

  • Лимит 10 активных API-токенов на юзера
  • Лимит 10 активных webhooks на юзера
  • Webhook URL должен быть публичным (private/loopback запрещены)
  • Webhook timeout 10 сек, body ≤ 1 МБ
  • Списание балансe юзера за каждый AI-вызов через API (как из UI)
  • Refund при ошибке генерации (HTTP 503 от нас → деньги вернутся)
  • Hash-сравнение через hmac.compare_digest — защита от timing-атак
